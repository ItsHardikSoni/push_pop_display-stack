# Stack Operations in Java

A menu-driven Java application that demonstrates the fundamental operations of a stack using an array.

## Features

- Push: Add an element to the top of the stack.
- Pop: Remove the top element from the stack.
- Display: Show all elements currently stored in the stack.
- Overflow Handling: Prevent insertion when the stack is full.
- Underflow Handling: Prevent deletion when the stack is empty.
- Menu-driven interface for performing operations.

## Data Structure

This project implements a stack using an array with a fixed capacity of 5 elements.

A stack follows the LIFO (Last In, First Out) principle. The last element inserted is the first element removed.

## Technologies Used

- Java
- Arrays
- Stack Data Structure
- Scanner Class

   git clone https://github.com/ItsHardikSoni/push_pop_display-stack.git
   \`\`\`

   \`\`\`bash
   cd push_pop_display-stack
   \`\`\`

3. Compile the Java program:

   \`\`\`bash

   \`\`\`

4. Run the application:
